Lerping@Home · texture pack

Metallum ad Infinitum

Procedural textures rendered by the Lerping@Home Metal shader engine. New renders land here automatically — drop an image in docs/textures/, add it to the manifest, push, and it appears.

Shader sources

Every texture in this pack is rendered from one of these runtime-compiled .metal shaders.

Hosted on GitHub Pages from the docs/ folder of codyhxyz/lerping-at-home. The agent adds textures by committing renders to docs/textures/ and entries to docs/textures/manifest.json — the site rebuilds on every push, about a minute later.
